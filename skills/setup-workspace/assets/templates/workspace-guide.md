# 私人职业工作区

仅属于当前使用者，被共享仓库 Git 忽略。个人事实和进展只维护一套。

```text
workspace/
  AGENTS.md
  README.md
  profile.md
  preferences.md
  resume/
  applications/
    AGENTS.md
    README.md
```

- `profile.md`：从用户提供的简历整理的事实基准，标明来源、确认状态和缺口。
- `preferences.md`：行业与岗位候选、用户确认的方向／地点，以及用户输入的薪资口径；建议与选择分开。
- `resume/`：原始简历、构建源文件与生成版本，不擅自覆盖原件。
- `applications/README.md`：具体个人机会与沟通进展总览。
- `applications/<公司>/log.md`：该公司岗位与联系线、事实时间线和下一步；有具体个人任务时再建。
- 公司 `records/` 保存原始沟通，`materials/` 保存定制草稿与面试准备，按需创建。

个人待整理记录、归档与猎头记录按需要才建立相应子目录。仅创建目录不表示已从简历生成事实或已确认偏好，初始化访谈按共享仓库的 setup-workspace Skill 执行。公共公司、渠道、人物与岗位研究仍维护共享 `data/`，不转私人 inbox。
