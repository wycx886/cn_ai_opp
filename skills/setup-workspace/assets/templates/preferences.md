# 职业方向与偏好（仅本地）

初始化状态：待访谈。下方“用户确认”区只有用户明确输入或认可后才填写；Agent 建议不自动成为筛选条件。

## 用户确认的偏好

- 行业／机构类型：待确认
- 岗位／职责方向：待确认
- 目标职级或合作方式：待确认
- 期望工作地点：待确认；不能沿用简历所在地推断
- 搬迁与现场／混合／远程安排：待确认
- 不考虑的方向与硬性约束：待确认
- 确认依据与日期：待填写

## 用户输入的薪资期望

- 筛选状态：待确认；也可由用户明确选择暂不设门槛／面议
- 期望范围：待用户输入
- 最低可接受条件：待确认，不自动根据期望范围设定
- 币种：待确认
- 月薪／年薪及薪月数：待确认
- 税前／税后：待确认
- 固定薪酬／奖金／股权／总包口径：待确认
- 用户说明与确认日期：待填写

薪资来源必须是用户输入；不从原简历、历史收入、市场均值或 Agent 建议补造。未确认的条件不用于排除机会，暂不提供薪资不阻止其他已授权任务。

## Agent 建议，尚未确认

根据简历提出约 3–5 个大方向；已有明确方向时直接沿用。候选需有履历依据，不给虚构匹配分数或擅自建议个人薪资底线。

## 沟通与表达偏好

- 沟通语言：待确认
- 表达风格与不希望出现的表述：待确认
- 跟进节奏：待确认；建议不等于授权自动联系

## 待确认问题

待填写。集中询问当前任务需要的行业、地点、岗位与薪资口径；用户未回复或预选选项不视为确认。

## 外部动作授权

本模板不授予任何发送、投递或预约权限。实际动作沿用使用者明确授权与本地规则，授权范围和真实进展记录在对应公司的私人日志中。
