# 私人工作区 · Agent 规则

先读共享仓库 `AGENTS.md` 和 setup-workspace Skill。这里保存使用者唯一的个人资料与进展，不上传公共仓库。

1. 新用户先提供简历，由 Agent 整理 `profile.md` 并标明事实来源和未决项；目录创建程序不负责事实提取。已有工作区直接复用，不覆盖原事实、不重复建档、不删旧资料。
2. `profile.md` 是个人事实基准；`preferences.md` 将 Agent 候选方向与用户确认的行业、地点、岗位及薪资分开。薪资由用户输入或明确表示不设门槛，不从简历或市场数据猜测。
3. 简历原件、构建源文件与生成版本放 `resume/`；沿用用户既有生成约定，不直接改写原件。语言与表达偏好记在 `preferences.md`。
4. 具体公司的定制材料与草稿放 `applications/<公司>/materials/`，沟通原件放 `records/`。公司目录和这些子目录在有实际个人任务时再建，不为了公开采集批量创建申请记录。
5. 更新个人进展先读 `applications/README.md`、其规则和公司日志，检查历史与不再接触要求。每个岗位／联系人独立记录，只有真实动作或用户确认才能记已发送、已投递、已回复。
6. 一位写入者维护同一公司 `log.md`；其他 Agent 的补充先保存唯一的原始记录，待归属或待合并的个人进展才用按需创建的 `applications/inbox/`。总览从公司日志汇总，不重复维护另一套状态。
7. 公开公司、招聘渠道和人物研究直接维护共享 `data/companies/`，不需要初始化个人资料，也不使用私人 inbox。
8. 私人简历、电话、聊天、个人薪资、凭据与授权不复制到共享文件、提交信息、Issue 或 PR。任务只要求研究或草稿时，不发送、投递或预约；实际动作依用户既有规则及明确授权范围执行。
